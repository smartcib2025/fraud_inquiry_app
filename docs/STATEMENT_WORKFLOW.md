# Statement & Live Interview Workflow (กก.1 บก.ปคบ.)

## 1. Supported Statement Types
- `COMPLAINT` (คำร้องทุกข์/กล่าวโทษ)
- `VICTIM` (คำให้การผู้เสียหาย)
- `WITNESS` (คำให้การพยาน)
- `SUSPECT` (คำให้การผู้ต้องสงสัย)
- `ACCUSED` (คำให้การผู้ต้องหา)
- `EXPERT` (คำให้การผู้เชี่ยวชาญ/เภสัชกร/นักวิทยาศาสตร์)
- `OFFICIAL` (คำให้การเจ้าพนักงาน/หน่วยงานรัฐ)

## 2. Interview Lifecycle
$$\text{START} \longrightarrow \text{IN\_PROGRESS} \longrightarrow \text{PAUSED} \longrightarrow \text{COMPLETED} \longrightarrow \text{IN\_REVIEW} \longrightarrow \text{APPROVED} \longrightarrow \text{FINAL}$$
