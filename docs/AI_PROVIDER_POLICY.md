# AI Provider Routing Policy

| Data Classification | Allowed Provider | Notes |
|---|---|---|
| `PUBLIC` | Approved Cloud, On-Premise, Local | For open-source intelligence |
| `INTERNAL` | On-Premise, Local Secure LLM | Standard police internal data |
| `CONFIDENTIAL` | On-Premise, Local Secure LLM | Case statements and financial records |
| `RESTRICTED` | Local Secure LLM Only | Sensitive national or undercover cases |
