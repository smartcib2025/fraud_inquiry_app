# Investigation Report & Case File Automation (กก.1 บก.ปคบ.)

## 1. Standard Report Structure
1. Case Background & Origin of Complaint
2. Summary of Verified Facts
3. Person & Suspect Profiles
4. Witness Statements (Approved only)
5. Evidence Inventory (SHA-256 Verified)
6. Timeline Chronology
7. Legal Element Analysis & Matrix
8. Outstanding Issues & Resolved Gaps
9. Investigator's Opinion Draft (`DRAFT FOR REVIEW`)
