# Modular Investigation Agents (กก.1 บก.ปคบ.)

1. **IntakeCaseTriageAgent**: Synthesizes intake complaints, extracts mentioned entities, and highlights initial urgency.
2. **InvestigationPlanningAgent**: Formulates investigation action plans, agency coordination targets, and evidence requests.
3. **TimelineAgent**: Reconstructs chronological event streams and detects alibi/login IP contradictions.
4. **EvidenceAnalysisAgent**: Extracts facts, amounts, and bank accounts from receipts and seized items.
5. **StatementComparisonAgent**: Cross-examines witness and suspect Q&A statements to uncover discrepancies.
6. **FinancialTransactionAgent**: Reconstructs money flow graphs, mule account layers, and transaction clustering.
7. **LegalMappingAgent**: Maps established case facts against statutory elements (e.g. Criminal Code Sec 343, Computer Crime Act).
8. **EvidenceGapAgent**: Identifies missing proof elements required to secure conviction before prosecutor transmittal.
