# Evidence Model & Artifact Hierarchy (กก.1 บก.ปคบ.)

## 1. Evidence Entity Specification
- `id`: UUID (Primary Key)
- `case_id`: UUID (Foreign Key to Cases)
- `evidence_number`: Official police exhibit identifier (e.g. `EV-CASE-142-001`)
- `title`: Descriptive exhibit title
- `evidence_type`: `DOCUMENT`, `IMAGE`, `AUDIO`, `VIDEO`, `DIGITAL_FILE`, `DEVICE`, `TRANSACTION`, `CHAT`
- `evidence_category`: `PHYSICAL`, `DIGITAL`, `DOCUMENTARY`, `TESTIMONIAL`
- `classification`: `PUBLIC`, `INTERNAL`, `CONFIDENTIAL`, `RESTRICTED`
- `status`: `REGISTERED`, `IN_CUSTODY`, `CHECKED_OUT`, `UNDER_ANALYSIS`, `RETURNED`, `ARCHIVED`, `DISPOSED`
- `integrity_status`: `NOT_CHECKED`, `VERIFIED`, `HASH_MISMATCH`, `DAMAGED`, `INCOMPLETE`, `REQUIRES_REVIEW`
- `review_status`: `NOT_REVIEWED`, `IN_REVIEW`, `REVIEWED`, `QUESTIONED`, `REQUIRES_ACTION`

## 2. Artifact Hierarchy
1. **`ORIGINAL`**: The pristine, write-blocked forensic copy directly acquired from source. Immutable.
2. **`FORENSIC_COPY`**: Bit-exact image generated via approved forensic software (e.g. FTK / Guymager).
3. **`WORKING_COPY`**: Copy used by investigators for day-to-day inspection and OCR parsing.
4. **`EXTRACTED_CONTENT`**: Normalized text, transaction tables, and chats parsed from working copy.
5. **`DERIVED_ARTIFACT`**: Sub-images, cropped QR codes, or audio clips.
6. **`AI_ANALYSIS_OUTPUT`**: Structured JSON cards and findings generated by modular AI agents.
